# Security Policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue containing exploit details or sensitive material.

Include a concise description, affected version, reproduction steps using synthetic data, and the expected impact. Please do not submit real credentials, personal information, customer data, or private catalog exports.

## Operational responsibility

This package performs local data transformation and does not provide authentication, network transport, persistence, or deployment controls. Applications embedding it are responsible for securing their data sources, generated files, runtime environment, and access boundaries.
